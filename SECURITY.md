# Security Policy

Spelunk is a local-first developer tool. It loads user-provided Python model factories, so only run capture workflows against code you trust.

## Reporting A Vulnerability

Please do not open public issues for security-sensitive reports.

Email:

```text
sarthakengala@gmail.com
```

Include:

- affected version
- operating system
- reproduction steps
- impact
- any suggested fix

## Supported Versions

The current pre-alpha line is `0.1.0a1`. Security fixes will be released as new alpha versions while the API is still stabilizing.
