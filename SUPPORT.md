# Support

Use GitHub issues for bugs, installation problems, and feature requests:

```text
https://github.com/sre0089/spelunk/issues
```

Before opening an issue, include:

- `spelunk --version`
- install method: pip, Homebrew, or source
- operating system and Python version
- the command or Python snippet you ran
- any relevant capture config, layer names, and error output

For security-sensitive reports, see [SECURITY.md](SECURITY.md).
